# Dataset Provenance Only

이 디렉토리에는 raw image dataset을 넣지 않습니다.

현재 공개본에는 다음처럼 작은 provenance 파일만 포함합니다.

- `CASIA2_subset/au_list.txt`
- `CASIA2_subset/tp_list.txt`
- `OpenSDID_subset/manifest.jsonl`
- `AI-GenBench_fakepart_subset/manifest.jsonl`
- `AI-GenBench_proxy/meta.json`

실제 이미지가 필요한 실험을 다시 돌리려면 사용자가 원본 dataset을 별도로 준비해서 같은 디렉토리 구조 아래에 채워 넣어야 합니다.
