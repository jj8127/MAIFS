# SHIELD 프로젝트 배경 — MAIFS 시스템과 DAAC 연구

## 1. 연구 배경: 이미지 위조 탐지의 필요성

오늘날 생성형 AI의 급속한 발전으로 이미지 위조는 두 가지 방향으로 진행된다. 첫째는 기존 이미지의 일부를 변형하는 **manipulation**(조작)이고, 둘째는 처음부터 AI가 생성하는 **AI-generated image**(AI 생성)이다. 이 두 위협은 탐지 방식이 근본적으로 다르기 때문에 단일 모델로 모두 잘 탐지하는 것이 매우 어렵다.

기존 연구들은 대부분 이 두 문제 중 하나만 잘 풀도록 설계되어 있었다. JPEG 압축 흔적을 분석하는 모델은 AI 생성 이미지를 탐지하지 못하고, AI 생성 이미지를 잡는 모델은 조작된 이미지를 탐지하지 못한다. 이것이 MAIFS 프로젝트가 시작된 핵심 동기다.

## 2. MAIFS 시스템: 4개 전문가 에이전트 협력

**MAIFS(Multi-Agent Image Forensic System)**는 서로 다른 관점에서 이미지를 분석하는 4개의 전문가 AI 에이전트가 협력하여 이미지 진위를 판별하는 시스템이다. 최종 판정은 3가지 클래스: **authentic(원본), manipulated(조작), ai_generated(AI 생성)**이다.

### 4개 전문가 에이전트

**FrequencyAgent (CAT-Net 백엔드, ~150MB)**
JPEG 이중 압축 흔적을 탐지한다. 이미지를 편집하면 JPEG 압축이 반복되고 특유의 주파수 패턴이 생긴다. 이 패턴을 DCT(Discrete Cosine Transform) 계수로 분석하는 것이 CAT-Net이다. 단, AI 생성 이미지는 이런 흔적이 없어 F1=0이다.

**NoiseAgent (MVSS-Net 백엔드, ~120MB)**
픽셀 단위 조작 마스크를 예측한다. 이미지를 조작하면 조작 영역과 원본 영역 사이의 노이즈 패턴이 달라진다. MVSS-Net은 이 차이를 학습하여 어느 영역이 조작되었는지 찾아낸다. 역시 AI 생성 이미지는 탐지하지 못한다.

**FatFormerAgent (CLIP ViT-L/14 + Forgery-Aware Adapter, ~890MB)**
AI 생성 이미지를 탐지하는 전문가다. CLIP의 강력한 시맨틱 표현 위에 Forgery-Aware Adapter(FAA)를 덧붙여 학습했다. FatFormer는 CVPR 2024 발표 논문이다. 반대로 부분 조작 이미지는 탐지하지 못한다(Manipulated F1=0).

**SpatialAgent (Mesorch 백엔드, ~100MB)**
ViT 기반으로 부분 조작 영역을 탐지한다. Mesorch를 도입하면서 CASIA2 데이터셋에서 mean_F1이 0.55에서 0.91로 대폭 상승했다.

### 시스템의 구조적 맹점과 핵심 통찰

이 4개 에이전트는 각자의 전문 영역에서는 강하지만, 서로의 맹점을 메워주는 관계다. 특히 **Frequency와 FatFormer는 서로 완전히 반대의 맹점**을 가진다: Frequency는 조작만 탐지하고, FatFormer는 AI 생성만 탐지한다.

이 구조적 불일치가 DAAC 연구의 핵심 신호가 된다. "두 에이전트가 서로 다른 판정을 내린다"는 **불일치 패턴 자체**가 이미지 유형에 대한 강력한 단서가 된다.

전체 서버 시스템의 추론 시간은 이미지 1장당 약 313ms이고, 모델 총 크기는 약 1.26GB다.

## 3. DAAC 연구: 불일치 패턴 기반 합의 메커니즘

### 기존 합의 방법의 한계

4개 에이전트의 판정을 합치는 가장 단순한 방법은 다수결이다. 더 정교한 방법으로는 COBRA(Root of Trust + Dynamic Reweighting + Attention)가 있다. 그러나 실데이터 실험에서 COBRA의 Macro-F1은 0.266에 불과했다.

왜 이렇게 낮은가? 에이전트들이 서로 다른 유형의 이미지에 대해 체계적으로 틀리기 때문이다. 단순 가중합은 이 구조를 이해하지 못한다.

### DAAC의 핵심 아이디어

**DAAC(Disagreement-Aware Adaptive Consensus)**의 핵심 가설은 이렇다: "에이전트 간 불일치 패턴 자체가 조작 유형을 암시하는 탐지 신호다."

DAAC는 4개 에이전트의 판정과 신뢰도로부터 **43차원 메타 특징**을 추출하고, 이를 Gradient Boosting(GBM) 메타 분류기에 학습시킨다. 메타 특징에는 개별 에이전트의 판정/신뢰도뿐만 아니라 **에이전트 간 불일치 여부**가 포함된다.

### 43차원 메타 특징 구성

| 특징 그룹 | 내용 |
|----------|------|
| 에이전트 판정 (one-hot) | 각 에이전트가 어떤 클래스로 판정했는지 (12차원) |
| 에이전트 신뢰도 | 각 에이전트의 confidence 값 (4차원) |
| 클래스별 확률 분포 | 에이전트별 3-class 확률 (12차원) |
| 불일치 플래그 | 에이전트 쌍 간 판정이 다른지 여부 (6차원) |
| 불일치 강도 | 판정이 다를 때 신뢰도 차이 크기 (6차원) |
| 앙상블 합의 통계 | 평균 신뢰도, 분산 등 (3차원) |

### DAAC 실험 결과

1,500장 실데이터(CASIA2 + GenImage BigGAN)에서 10-seed 반복 실험 결과:

| 방법 | Macro-F1 | 비고 |
|------|----------|------|
| COBRA (기존) | 0.266 | 단순 가중 합의 |
| **DAAC-GBM** | **0.8613** | 43-dim 메타 분류기 |
| Macro-F1 차이 | +0.595 | Wilcoxon p=0.00195 |

Protocol-M (6개 데이터 조합, 60회): sign 60/0, p=1.63e-11, mean delta +0.493

### 가장 중요한 특징: disagree_frequency_fatformer

GBM feature importance 분석에서 가장 중요한 특징이 `disagree_frequency_fatformer`로, 중요도 **56.5%**를 차지했다. 이것은 "Frequency 에이전트와 FatFormer 에이전트의 판정이 서로 다른가?"를 나타내는 binary 플래그다.

해석: 진짜 조작 이미지가 들어오면 Frequency는 조작 신호를 잡고 FatFormer는 AI 생성이 아님을 확인한다. AI 생성 이미지가 들어오면 반대다. 둘이 동의하면 authentic일 가능성이 높다. 이 패턴이 분류에서 절반 이상의 정보를 담고 있다.

DAAC 합의 계층의 추론 시간은 0.069ms로 전체의 0.02% 미만이다. 메타 분류기가 매우 가볍기 때문이다.

이 연구는 KIPS 2026에 논문으로 제출 예정이다.

## 4. SHIELD 연구의 필요성: Edge 배포 도전

DAAC는 서버에서 높은 성능을 달성했다. 그러나 현실 세계의 많은 응용에서 이미지는 서버로 전송되지 않고 로컬에서 처리되어야 한다. 의료 영상 분석, 저널리즘 현장, 개인 프라이버시 보호 등의 상황에서는 **On-Device(기기 내) 처리**가 필수다.

문제는 현재 MAIFS가:
- 모델 총 크기: **~1.26GB** (RPi5의 8GB RAM 중 15%)
- 추론 시간: **~313ms** (실시간 불가능)
- 메모리 사용: **~4GB 이상** (동시 로드 시)

이기 때문에 Raspberry Pi 5 같은 엣지 디바이스에서 현실적으로 동작하기 어렵다.

### SHIELD 연구 목표

**SHIELD(Shapley-based Hardware-aware Interaction-preserving Ensemble Lightweighting for on-Device forensics)**는 DAAC의 성능을 최대한 유지하면서 RPi5에 배포 가능한 경량 아키텍처를 설계하는 것이 목표다.

| 지표 | 서버 현재 | RPi5 목표 |
|------|----------|---------|
| 모델 크기 | ~1.26GB | <500MB (이상적 ~180MB) |
| 추론 시간 | ~313ms | <1초 |
| Macro-F1 | 0.8613 | >0.80 |
| 메모리 | ~4GB+ | <4GB |

### 왜 Raspberry Pi 5인가?

Galaxy S26 같은 스마트폰을 쓰지 않고 RPi5를 선택한 이유:
- **오픈 하드웨어**: 재현성 보장, 학술 표준
- **확장성**: Hailo-8L NPU(13 TOPS INT8) 추가 가능
- **실측 가능**: CPU 벤치마크가 공개된 값과 일치

RPi5 사양: Cortex-A76 4코어 @2.4GHz, 8GB LPDDR4X RAM

단순히 모델을 작게 만드는 것이 목표가 아니다. 핵심 질문은 세 가지다:
1. 4개 에이전트 중 **어떤 조합이 최적**인가? (상호작용 기반 선택)
2. 각 백본을 **얼마나 경량화**해도 포렌식 신호가 유지되는가?
3. **어떤 구조**로 배포해야 RPi5에서 실시간에 가깝게 동작하는가?

이 세 질문에 답하기 위해 SHIELD 연구는 Phase 1(에이전트 가치 분석)부터 Phase 4(실제 RPi5 배포)까지 단계적으로 진행된다.
